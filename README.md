# comfyui-nodes

ComfyUI custom nodes by bemoregt. Each node lives in its own branch (formerly a separate repository).

## Install

Clone the branch for the node you want into `ComfyUI/custom_nodes`:

```bash
cd ComfyUI/custom_nodes
git clone -b <Branch> --single-branch https://github.com/bemoregt/comfyui-nodes.git <Branch>
pip install -r <Branch>/requirements.txt   # if present
```
